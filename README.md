# TripWay

Site multipágina de uma empresa fictícia de turismo nacional, criado somente com HTML.

## Integrante

- Erick Medeiros Dantas 576627

## Páginas

- Início
- Destinos
- Pacotes
- Reserva

## Estrutura do projeto

```text
tripway-erick/
├── index.html
├── images/
├── pages/
│   ├── destinos.html
│   ├── pacotes.html
│   └── reserva.html
└── README.md
```

## Conteúdo utilizado

- HTML semântico
- Navegação entre páginas com caminhos relativos
- Imagens locais com texto alternativo
- Listas de destinos e serviços
- Formulário de contato e reserva

Para abrir o projeto, basta executar o arquivo `index.html` em um navegador.
